# Embed EARTH RIGHT NOW

Use this iframe to place the current ERN live experience on a website:

```html
<iframe
  src="https://ern-inc.github.io/earth-right-now/embed.html"
  title="EARTH RIGHT NOW"
  loading="lazy"
  allow="autoplay; encrypted-media; picture-in-picture; web-share; fullscreen"
  allowfullscreen
  style="width:100%;aspect-ratio:16/9;border:0">
</iframe>
```

Official site: https://ern-inc.github.io/earth-right-now/

The embed automatically follows ERN's current live stream via `live.json`.
